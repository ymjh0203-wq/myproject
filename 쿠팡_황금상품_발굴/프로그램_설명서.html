★ 프로그램 설명서

쿠팡 황금상품 발굴 프로그램,
무엇을 어떻게 만들었나

중국에서 소싱해 쿠팡에 파는 "크무비(크고·무겁고·객단가 높은)" 상품을 자동으로 찾아주는 도구예요. 프로그램은 두 개, 서로 이어지는 흐름이고, 전부 네이버 공식 API 위에서 돌아갑니다. 아래에서 코딩을 몰라도 전체 그림이 잡히도록 순서대로 설명할게요.

find_keywords.py — 유망 키워드 발굴 main.py — 실제 상품 크무비 검증
01

전체 그림

두 프로그램은 순서가 있어요. 하나가 "어디를 파볼지" 찾아주면, 다른 하나가 "진짜 괜찮은지" 검증합니다.

키워드 발굴 → (사람이 직접 소싱 조사) → 정보 입력 → 크무비 검증, 총 5단계 흐름

핵심은 2번 단계는 프로그램이 대신 못 해준다는 점이에요. 실제 상품의 크기·무게·판매가는 1688/타오바오 같은 중국 소싱 사이트에만 있는 정보라서, 사장님이 직접 조사해서 입력해야 그다음 검증이 가능합니다.

02

크무비 검증 — main.py

사장님이 직접 조사한 상품이 진짜 "크무비" 조건에 맞는지 계산해서 점수 매기는 프로그램이에요.

products_template.csv 한 줄(상품 하나)마다 이 과정을 반복합니다

products_template.csv에 상품명·검색키워드·가로·세로·높이·실중량·판매가를 한 줄씩 입력하면:

  1. 제외키워드 확인 — 브랜드명이나 금지품목이 포함되어 있으면 탈락 사유를 남기고 제외
  2. 크무비 조건 확인 — 가로+세로+높이 200cm 이상, (실중량과 부피중량 중 큰 값) 20kg 이상, 판매가 20만~100만원, 셋 다 만족해야 통과
  3. 통과한 상품만 네이버 검색광고 API로 검색량을, 데이터랩 API로 3년 계절성을 조회
  4. 검색량·계절성·가격·크무비 강도를 종합해 100점 만점 점수를 매김

결과는 output/골든상품_결과.csv에 점수 높은 순으로 저장됩니다.

03

키워드 발굴 — find_keywords.py

아직 특정 상품이 정해지지 않았을 때, "어느 키워드를 파봐야 할지" 넓게 찾아주는 프로그램이에요. 3단계에 걸쳐 계속 기능을 붙여왔습니다.

키워드 발굴은 3단계에 걸쳐 점점 더 정교해졌어요 (아래 04번 항목 참고)

04

만들어진 순서

키워드 발굴 프로그램은 한 번에 완성한 게 아니라, 실제로 써보면서 필요한 걸 하나씩 더했어요.

기초 단계

크무비 검증 + 키워드 발굴 뼈대

상품 정보를 입력하면 크무비 조건을 확인하는 main.py와, 네이버 API로 검색량·계절성을 조회하는 기본 골격을 먼저 만들었어요.

1단계

"관련 없는 키워드가 왜 나오지?" 문제 해결

캠핑용품을 찾는데 "카드지갑", "이어폰"이 섞여 나오는 문제가 있었어요. 시드 키워드와 실제 관련이 있는지, 크무비(대형) 가능성이 있는지를 단어 사전으로 판별하는 로직을 추가했습니다.

2단계

중국 소싱 가능성 추정

일반 공산품·범용 소재 느낌이 있는지, 반대로 전자·식품·화장품처럼 소싱이 까다로운 신호가 있는지를 봐서 "중국에서 구하기 쉬운 상품인가"를 추정하는 기능을 더했어요.

3단계

위험도 분류 + 최종 등급 + 엑셀 분리 저장

전기제품·배터리·어린이제품·인증 등 판매 전 검토가 필요한 요소를 자동으로 분류하고, 지금까지의 모든 점수를 하나로 합쳐 S/A/B/C 등급을 매기도록 했습니다. 결과도 "추천 후보"와 "제외/검토 필요"로 나눠 엑셀 두 개로 저장하도록 마무리했어요.

06

등급 읽는 법

키워드 발굴 결과의 추천등급 컬럼은 지금까지의 모든 점수(검색량·관련성·소싱가능성·위험도)를 합친 최종 판정이에요.

S

점수도 높고, 관련성·소싱가능성·위험도 등 모든 조건을 충족한 최상위 후보

A

전반적으로 양호. 검토해볼 가치가 충분한 후보

B

보통 수준. 다른 후보와 비교해서 순위를 매길 때 참고

C

검색량이 낮거나, 관련성·소싱가능성이 떨어지는 후보

검색량이 높아도 S가 안 나올 수 있어요 관련성이 낮거나, 정보성 키워드(예: "~하는법")이거나, 브랜드가 섞여 있거나, 위험 요소가 있으면 점수가 아무리 높아도 S등급은 주지 않도록 설계했어요. "그냥 검색 많이 되는 것"과 "진짜 살 만한 상품"을 구분하려는 의도예요.
07

용어 쉽게 알기

코딩을 몰라도 이 프로그램을 이해하는 데 필요한 개념만 골라 쉬운 말로 풀었어요.

파이썬(Python) 언어

이 프로그램을 짠 프로그래밍 언어 이름이에요. 사람이 "이거 하고, 저거 하고" 순서대로 적어두면, 컴퓨터가 그대로 실행해주는 도구라고 생각하시면 됩니다. .py로 끝나는 파일이 전부 파이썬 코드예요.

API 데이터 창구

네이버 같은 회사가 "이 주소로 물어보면 데이터를 알려줄게요"라고 열어둔 창구예요. 저희 프로그램은 이 API를 통해 네이버에게 "이 키워드 검색량 얼마야?"라고 물어보고 답을 받아옵니다.

함수(function) 미니 기계

"입력을 넣으면 정해진 작업을 해서 결과를 내놓는" 작은 단위예요. 예를 들어 check_kmubi()라는 함수는 상품 정보를 넣으면 크무비 조건 통과 여부를 계산해서 돌려줍니다.

모듈(파일) 서랍

.py 파일 하나하나가 관련된 함수들을 모아둔 서랍이에요. "검색량 조회" 서랍, "위험도 판별" 서랍처럼 역할별로 나눠뒀기 때문에, 하나를 고쳐도 다른 서랍은 안 건드립니다.

CSV / xlsx 표 파일

둘 다 엑셀에서 열리는 표 형식이에요. CSV는 글자만 있는 가벼운 표, xlsx는 서식·시트가 들어가는 진짜 엑셀 파일이에요. 이 프로그램은 입력도 표, 출력도 표라서 엑셀만 다룰 줄 알면 충분해요.

설정값(config) 조절 다이얼

config.py 안의 숫자들이에요. "부피 200cm 이상"의 200이라는 숫자를 바꾸고 싶으면, 코드를 고칠 필요 없이 이 숫자만 바꾸면 됩니다.

"_추정" 컬럼 가장 중요

결과표에서 이름 끝에 "_추정"이 붙은 컬럼은 전부 단어 매칭으로 짐작한 값이에요. 실제로 조사한 사실이 아니라 참고용 힌트라는 뜻이니, 이 컬럼만 보고 최종 판단하시면 안 돼요.

08

한계와 주의사항

이 프로그램이 못 하는 것, 조심해야 할 것을 정리했어요.

진짜 AI가 판단하는 게 아니에요 관련성·크무비 가능성·소싱 가능성·위험도는 전부 미리 정해둔 단어 사전과 문자열이 겹치는지를 보는 "규칙 기반 추정"이에요. 사전에 없는 단어는 놓칠 수 있고, 우연히 겹치는 단어 때문에 엉뚱하게 판정될 수도 있습니다.
실제 상품 크기·무게는 절대 알 수 없어요 키워드만 갖고는 그 키워드로 팔리는 상품이 실제로 몇 cm, 몇 kg인지 알 방법이 없어요. 진짜 크무비 검증은 반드시 main.py로, 실제 상품 정보를 입력해서 하셔야 합니다.
제외키워드.csv는 완전한 법정 목록이 아니에요 해외직구 금지·제한 품목은 관세청이 정하고 계속 바뀌는데, 이 파일은 참고용 출발점일 뿐이에요. 실제 소싱 전엔 관세청 통관정보포털이나 관세사 확인이 꼭 필요합니다.
1688·타오바오는 절대 자동으로 접속하지 않아요 중국 쇼핑몰 크롤링이나 로그인 우회 같은 기능은 만들지 않았어요. 소싱 조사는 사장님이 직접 하셔야 합니다.
네이버 API는 하루 호출 한도가 있어요 특히 데이터랩(계절성)은 한도를 넘기면 그날은 조회가 막혀요. 그럴 땐 검색량 등 다른 정보만으로 진행되고, 다음날 한도가 초기화되면 다시 정상 작동합니다.
09

빠른 사용법
