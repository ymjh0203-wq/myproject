주문관리 프로그램 · 새 컴퓨터 설치 가이드

이 가이드 하나만 순서대로 따라 하시면 다른 컴퓨터에서도 프로그램을 쓸 수 있습니다.

전체 순서 (크게 3단계)
  1. 지금 쓰는 컴퓨터에서 → 폴더를 USB로 복사
  2. 새 컴퓨터에서 → 설치 파일 실행
  3. 쿠팡 Wing에 새 컴퓨터 IP 등록 (가장 중요)

⚠️ 먼저 꼭 아셔야 할 것

폴더를 그냥 복사만 해서는 작동하지 않습니다. 아래 3단계를 모두 거쳐야 합니다.

특히 3단계(쿠팡 IP 등록)를 빠뜨리면, 프로그램은 켜지지만 수집하기를 눌러도 전부 실패합니다.

1

지금 쓰는 컴퓨터에서 — 폴더 복사

USB 메모리를 꽂고 시작하세요
  • 프로그램 폴더 안의 새컴퓨터로_복사하기.bat 을 더블클릭합니다.
  • 어디에 복사할지 물어봅니다 → USB 드라이브 경로를 적으세요. (예: E:\주문관리)
  • 데이터베이스도 복사할지 물어봅니다.
    • y = 지금까지의 주문·CS메모가 그대로 넘어감
    • n = 새 컴퓨터는 빈 상태로 시작 (상점을 다시 등록해야 함)
💡 용량이 큰 .venv 폴더는 자동으로 빠집니다
이 컴퓨터 전용 파일이라 옮겨도 작동하지 않습니다. 새 컴퓨터에서 2단계로 다시 만들어집니다.
🔒 이 폴더에는 실제 API 키와 고객 개인정보(이름·전화번호·통관고유부호)가 들어 있습니다
USB를 잃어버리지 않게 주의하시고, 메일·카카오톡으로는 보내지 마세요.
2

새 컴퓨터에서 — 설치

USB를 새 컴퓨터에 꽂고 시작하세요

2-1. 폴더를 옮깁니다

  • USB 안의 폴더를 바탕화면처럼 단순한 위치로 복사합니다.
  • ❌ OneDrive 폴더 안에는 두지 마세요 (동기화 오류가 납니다).
  • ❌ 폴더를 여러 겹 깊숙한 곳에 두지 마세요 (설치가 실패할 수 있습니다).

2-2. 설치 파일 실행

  • 설치.bat 을 더블클릭합니다.
  • 검은 창에 글자가 계속 올라가는 게 정상입니다. 3~10분 걸립니다. 중간에 닫지 마세요.
  • 설치가 정상적으로 끝났습니다 가 나오면 완료입니다.
⚙️ "Python is not installed" 이라고 나오면
파이썬을 먼저 깔아야 합니다:
  1. python.org/downloads/windows 접속
  2. Python 3.12.x — Windows installer (64-bit) 다운로드
  3. 설치 화면 맨 아래 「Add python.exe to PATH」 체크박스를 반드시 체크 ← 이거 빠뜨리면 안 됩니다
  4. 설치 완료 후 설치.bat 을 다시 실행
3

쿠팡 Wing에 새 컴퓨터 IP 등록

이 단계를 빠뜨리면 수집하기가 전부 실패합니다

쿠팡 오픈API는 등록된 인터넷 주소(IP)에서만 작동합니다. 새 컴퓨터가 다른 인터넷(다른 사무실·집·테더링)을 쓰면 IP가 달라서 차단됩니다.

확인 방법

  • 새 컴퓨터에서 myip.com 에 접속 → 나오는 IP 주소를 적습니다.
  • 지금 쓰는 컴퓨터의 IP와 같으면 → 등록할 필요 없습니다 (같은 인터넷을 쓰는 것).
  • 다르면 → 아래처럼 등록합니다.

등록 방법

  • 쿠팡 Wing → 판매자정보 → 오픈API 키 발급/관리 에서 그 IP를 추가합니다.
  • 상점 3개(굿디얼·에버온·미노바) 각각 따로 등록해야 합니다.
✓

실행하기

  • 주문관리_실행.bat 을 더블클릭하면 프로그램 창이 열립니다.
  • 바탕화면에 두고 쓰시려면: 주문관리_실행.bat 우클릭 → 바로 가기 만들기 → 만들어진 바로가기를 바탕화면으로 옮기세요.
✅ 여기까지 하면 새 컴퓨터에서 프로그램을 쓸 수 있습니다
i

알아두실 점

두 컴퓨터의 데이터는 따로 쌓입니다
자동 동기화가 안 됩니다. A컴퓨터에서 CS메모를 쓰면 B컴퓨터에는 안 보입니다. 한 대를 정해서 주로 쓰시길 권합니다. (쿠팡에서 수집하는 주문 정보 자체는 어느 컴퓨터에서든 똑같이 받아옵니다. 따로 노는 건 CS메모처럼 직접 입력한 내용입니다.)

문자 발송 기능
「휴대폰과 연결」(Phone Link) 앱을 통해 보내는 방식이라, 새 컴퓨터에서도 그 앱에 휴대폰을 연결해야 작동합니다.

프로그램을 수정했을 때
이 컴퓨터에서 기능을 고치면 새 컴퓨터에는 자동 반영되지 않습니다. 새컴퓨터로_복사하기.bat 을 다시 실행해 덮어쓰면 됩니다. 이때는 설치.bat 을 다시 돌릴 필요가 없습니다.
