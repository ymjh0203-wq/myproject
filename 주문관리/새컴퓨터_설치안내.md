# 다른 컴퓨터에 주문관리 프로그램 설치하기

이 문서 하나만 따라 하시면 됩니다. 크게 **3단계**입니다.

---

## 1단계 — 지금 이 컴퓨터에서: 폴더 복사하기

`새컴퓨터로_복사하기.bat` 을 더블클릭하세요.

1. **어디에 복사할지** 물어봅니다 → USB 드라이브 경로를 적으세요 (예: `E:\주문관리`)
2. **데이터베이스도 복사할지** 물어봅니다
   - `y` (복사함) → 지금까지의 주문·CS메모·상점 등록이 그대로 넘어갑니다
   - `n` (복사 안 함) → 새 컴퓨터는 빈 상태로 시작하고, 상점(쿠팡 계정)을 다시 등록해야 합니다

> ⚠️ 이 폴더에는 **실제 API 키**와 **고객 실명·전화번호·통관고유부호**가 들어 있습니다.
> USB는 잃어버리지 않게 주의하시고, 메일이나 카카오톡으로 보내지 마세요.

복사에서 `.venv` 폴더(378MB)는 일부러 제외됩니다. 이 컴퓨터 전용 파일이라 옮겨봐야 작동하지 않고, 새 컴퓨터에서 2단계로 새로 만들어집니다.

---

## 2단계 — 새 컴퓨터에서: 설치하기

### 2-1. 폴더를 옮깁니다
복사한 폴더를 **바탕화면** 같은 단순한 위치에 두세요.

- ❌ OneDrive 안에는 두지 마세요 (동기화 때문에 오류가 납니다).
- ❌ 폴더를 여러 겹 깊숙한 곳에 두지 마세요. 윈도우 경로 260자 제한 때문에 설치가 실패합니다.
  (`설치.bat` 이 미리 검사해서 경고해줍니다)

### 2-2. 파이썬이 있는지 확인
`설치.bat` 을 더블클릭하면 자동으로 확인합니다.

**"Python is not installed" 라고 나오면** 파이썬을 먼저 깔아야 합니다:

1. https://www.python.org/downloads/windows/ 접속
2. **Python 3.12.x — Windows installer (64-bit)** 다운로드
3. 설치 화면 맨 아래 **`Add python.exe to PATH` 체크박스를 반드시 체크** ← 이거 빠뜨리면 안 됩니다
4. 설치 완료 후 `설치.bat` 을 다시 더블클릭

### 2-3. 설치 완료까지 기다립니다
`설치.bat` 이 알아서 다 합니다. **3~10분** 걸립니다 (인터넷 속도에 따라 다름).
검은 창에 글자가 계속 올라가는 게 정상입니다. 중간에 닫지 마세요.

`Setup finished successfully.` 가 나오면 끝입니다.

---

## 3단계 — 쿠팡에 새 컴퓨터 IP 등록 ⚠️ **가장 중요**

이 단계를 빼먹으면 **수집하기를 눌러도 전부 실패(403)** 합니다.

쿠팡 오픈API는 **등록된 인터넷 주소(IP)에서만** 작동합니다.
새 컴퓨터가 **다른 인터넷**(다른 사무실, 집, 핸드폰 테더링)을 쓴다면 IP가 달라서 차단됩니다.

### 확인 방법
새 컴퓨터에서 https://www.myip.com 접속 → 나오는 IP 주소를 적어둡니다.
이 컴퓨터의 IP와 **같으면** 등록할 필요 없습니다(같은 인터넷을 쓰는 것).

### 다를 경우
쿠팡 **Wing → 판매자정보 → 오픈API 키 발급/관리** 에서 그 IP를 추가 등록하세요.
**상점 3개(굿디얼·에버온·미노바) 각각 따로 등록해야 합니다.**

---

## 실행하기

`주문관리_실행.bat` 더블클릭 → 프로그램 창이 열립니다.

바탕화면에 두고 쓰시려면: `주문관리_실행.bat` 우클릭 → **바로 가기 만들기** → 만들어진 바로가기를 바탕화면으로 옮기세요.

---

## 알아두실 점

### 두 컴퓨터의 데이터는 따로 쌓입니다
자동 동기화가 안 됩니다. A컴퓨터에서 CS메모를 쓰면 B컴퓨터에는 안 보입니다.
**한 대를 정해서 주로 쓰시는 걸 권합니다.** (쿠팡에서 수집하는 주문 정보 자체는 어느 컴퓨터에서든 똑같이 받아옵니다. 따로 노는 건 CS메모처럼 직접 입력한 내용입니다.)

### 문자 발송 기능
"휴대폰과 연결"(Phone Link) 앱을 통해 보내는 방식이라, **새 컴퓨터에서도 그 앱에 휴대폰을 연결해야** 작동합니다.

### 프로그램을 수정했을 때
이 컴퓨터에서 기능을 고치면 새 컴퓨터에는 자동 반영되지 않습니다.
`새컴퓨터로_복사하기.bat` 을 다시 실행해서 덮어쓰면 됩니다. 이때는 `설치.bat` 을 다시 돌릴 필요가 **없습니다** (패키지는 그대로이므로).

---

## 문제가 생기면

| 증상 | 원인 / 해결 |
|---|---|
| 수집하기 누르면 전부 403 오류 | 3단계 IP 등록을 안 했습니다 |
| `Python is not installed` | 2-2단계, `Add python.exe to PATH` 체크 확인 |
| 설치 중 오류로 멈춤 | 인터넷 연결 확인 후 `설치.bat` 다시 실행 |
| `이 폴더의 경로가 너무 깁니다` | 폴더를 바탕화면 등 짧은 위치로 옮기고 다시 실행 |
| 가상환경 생성 실패 | 폴더가 OneDrive 안에 있는지 확인 → 바탕화면으로 옮기기 |
| 실행하면 창이 잠깐 뜨고 꺼짐 | `설치.bat` 을 먼저 실행했는지 확인 |
| 상점 목록이 비어 있음 | 데이터베이스를 복사하지 않은 경우입니다. 설정 화면에서 상점을 다시 등록하세요 |
