# 벤치마킹 소싱 기능 명세

작성일: 2026-09-07  
상태: 구현 전 검토안

## 1. 목표

국내에서 잘 팔리는 경쟁상품 URL 하나를 입력하면 프로그램이 상품정보를 확인하고,
타오바오에서 동일하거나 유사한 공급상품 후보를 찾아 비교한 뒤 상위 후보를 사용자가
선택할 수 있게 한다.

단순히 타오바오 이미지검색 결과의 앞 3개를 가져오지 않는다. 여러 경로로 후보를
수집하고, 상품 일치도와 판매 적합도를 평가해서 추천한다.

## 2. 사용자 흐름

1. 사용자가 국내 경쟁상품 URL을 입력한다.
2. 프로그램이 보이는 브라우저에서 상품 페이지를 연다.
3. 상품명, 대표이미지, 판매가, 판매점, 리뷰 신호를 수집한다.
4. 사용자가 수집된 기준상품 정보를 한 번 확인한다.
5. 프로그램이 타오바오 후보를 두 경로로 찾는다.
   - 대표이미지를 이용한 유사이미지 검색
   - 상품명 핵심어를 중국어로 변환한 키워드 검색
6. 검색 결과에서 최대 20개 후보를 수집한다.
7. 후보별 상품명, 이미지, 가격, 판매량, 리뷰수, 판매점 정보를 수집한다.
8. 후보 점수를 계산하여 상위 3개를 추천한다.
9. 사용자가 한 개 이상을 선택해 `products_raw`에 저장한다.
10. 선택 상품은 공통 가공 단계로 이동한다.

## 3. 화면 구성

### 3.1 기준상품 입력

- 국내 상품 URL 입력란
- 찾을 추천상품 수: 기본 3개, 1~10개 설정
- `분석 시작` 버튼
- 최근 분석 URL 목록

### 3.2 기준상품 확인

- 대표이미지
- 원본 상품명
- 판매가
- 판매점
- 리뷰수 또는 확인 가능한 인기 신호
- 자동 추출한 메인키워드 후보
- 자동 추출한 서브키워드 후보
- `이 상품으로 타오바오 찾기` 버튼

잘못 추출된 이미지나 상품명은 사용자가 이 화면에서 교체하거나 수정할 수 있다.

### 3.3 타오바오 후보 비교

각 후보 카드에 다음 항목을 표시한다.

- 대표이미지
- 중국어 상품명과 한국어 번역명
- 타오바오 가격과 원화 환산가격
- 판매량
- 리뷰수
- 판매점
- 기준상품과 이미지 유사도
- 추천점수
- 타오바오 원본 링크
- 선택 체크박스

정렬 기준은 추천순, 가격순, 판매량순, 리뷰순을 제공한다.

## 4. 후보 검색 전략

### 4.1 이미지 검색

기준상품 대표이미지로 타오바오 이미지검색을 시도한다.

- 로그인된 고정 브라우저 프로필 사용
- 브라우저를 검색 단계마다 열고 닫지 않고 한 작업 동안 유지
- 로그인이나 캡차 발생 시 창을 닫지 않고 사용자가 처리할 시간을 제공
- 화면에 상품이 보이지만 DOM 링크가 잡히지 않을 때를 대비해 네트워크 응답과
  페이지 데이터도 함께 확인

### 4.2 중국어 키워드 검색

이미지검색 실패 또는 결과 부족 시 자동으로 보완한다.

1. 국내 상품명에서 브랜드명, 광고성 수식어, 배송 문구를 제거한다.
2. 제품 종류, 용도, 소재, 형태를 핵심어로 분리한다.
3. 핵심어를 중국어 검색어로 변환한다.
4. 타오바오 검색 결과를 수집한다.

예시:

`전동 충전식 철근 절단기 휴대용` → `充电式 钢筋切断机 便携`

### 4.3 후보 병합

이미지검색 후보와 키워드검색 후보를 상품 ID 기준으로 합치고 중복을 제거한다.
최소 10개, 최대 20개를 평가 대상으로 삼는다.

## 5. 추천점수

초기 버전은 계산 근거가 보이는 규칙 기반 점수를 사용한다.

| 평가항목 | 비중 | 설명 |
|---|---:|---|
| 이미지 유사도 | 40 | 기준상품과 대표이미지의 시각적 유사도 |
| 상품명·속성 일치 | 20 | 제품 종류, 용도, 소재, 형태 일치 여부 |
| 판매량 | 15 | 타오바오 판매 신호 |
| 리뷰수 | 10 | 구매자 검증 신호 |
| 가격 경쟁력 | 10 | 후보군 중 상대적인 가격 수준 |
| 판매점 신뢰 신호 | 5 | 확인 가능한 판매점 정보 |

다음 후보는 점수와 별개로 경고한다.

- 브랜드·상표 의심 상품
- 전기용품, 어린이제품 등 인증 가능성이 있는 상품
- 의약품·식품·화장품 등 구매대행 제한 가능성이 큰 상품
- 이미지나 상세설명에 타 판매자 워터마크가 있는 상품

## 6. 사람의 검수 지점

반자동 프로그램이므로 다음 결정은 사용자가 한다.

- 기준상품 이미지와 상품명이 맞는지 확인
- 타오바오 추천 후보 중 실제로 동일·유사한 상품 선택
- 브랜드·인증·금지상품 위험 확인
- 최종 옵션과 판매가 확인
- 마켓 등록 승인

프로그램은 캡차를 자동 우회하지 않는다.

## 7. 데이터 저장

### benchmark_seeds 보강

- 기준상품 URL
- 국내 마켓
- 상품명
- 대표이미지 URL 및 로컬 사본
- 판매가
- 판매점
- 리뷰수
- 메인·서브키워드 후보
- 분석일시

### sourcing_candidates 신규 테이블

- 기준상품 ID
- 타오바오 상품 ID 및 URL
- 검색경로: image 또는 keyword
- 순위
- 이미지 유사도
- 상품명 일치도
- 가격점수
- 판매량점수
- 리뷰점수
- 총 추천점수
- 선택 여부
- 수집 원본 JSON
- 생성일시

사용자가 선택한 후보만 `products_raw`에 저장한다.

## 8. 실패 처리

| 상황 | 처리 |
|---|---|
| 국내 상품 페이지 보안확인 | 브라우저를 유지하고 사용자 처리 대기 |
| 대표이미지 추출 실패 | 기준상품 확인 화면에서 이미지 교체 가능 |
| 타오바오 로그인 필요 | 같은 창에서 사용자 로그인 후 자동 재개 |
| 타오바오 이미지검색 결과 없음 | 중국어 키워드검색으로 자동 전환 |
| 후보가 3개 미만 | 확보된 후보만 표시하고 부족 사유 안내 |
| 상세정보 일부 누락 | 누락 필드를 표시하고 후보 자체는 유지 |
| 캡차 반복 | 작업을 중단하고 재시도 시점을 사용자에게 안내 |

## 9. 구현 단계와 합격 기준

### 1단계: 기준상품 분석

- 스마트스토어 상품 URL 3개로 테스트
- 상품명과 대표이미지를 3개 모두 정확히 표시
- 보안확인 발생 시 창이 자동으로 닫히지 않음

### 2단계: 타오바오 후보 검색

- 이미지검색과 키워드검색을 각각 독립 테스트
- 결과 화면에 보이는 상품을 프로그램도 인식
- 중복 제거 후 후보 10개 이상 확보 또는 부족 이유 표시

### 3단계: 후보 평가

- 후보 이미지 유사도 계산
- 가격·판매량·리뷰 신호를 포함한 추천점수 표시
- 추천 상위 3개와 사용자의 육안 판단이 크게 어긋나지 않는지 확인

### 4단계: 저장

- 선택 후보만 Supabase에 저장
- 같은 타오바오 상품 중복 저장 방지
- 기준상품과 타오바오 후보의 연결관계 유지

각 단계는 실제 테스트가 통과된 뒤 다음 단계로 넘어간다.

## 10. 현재 코드 처리 방침

- Supabase, 환율, 설정, 대시보드 구조는 유지한다.
- 기존 `seed.py`와 `taobao_image_search.py`는 재사용 가능 부분만 남기고 재구성한다.
- 진단용 배치파일과 임시 오류처리는 최종 안정화 후 정리한다.
- `AI 소싱`과 `벤치마킹 소싱`은 별도 입구로 유지하되, 후보 평가와 상품 가공은
  공통 서비스로 합친다.
