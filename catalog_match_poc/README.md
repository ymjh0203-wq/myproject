# 쿠팡 상품 일괄등록 작업 도우미

## 엑셀로 여러 상품 등록 준비

1. 프로그램의 `엑셀 양식 저장`을 눌러 양식을 원하는 폴더에 저장합니다.
2. 엑셀 `상품등록` 시트의 10행부터 쿠팡 상품 URL을 입력합니다.
3. 각 행에서 `등록 선택`, `배송비 방식`, `WING 처리 방식`, `상세 이미지 방식`을 선택하고 저장합니다.
4. 프로그램의 `엑셀 파일 불러오기`를 누르고 작성한 파일을 고릅니다.
5. 불러오기 결과를 확인한 뒤 `예`를 누르면 첫 상품부터 자동등록을 시작합니다.

엑셀에는 WING 비밀번호, 쿠키, API 비밀키를 넣지 않습니다. 자동등록은 프로그램에서 현재 준비한 전용 Chrome/WING 로그인 상태를 사용하며, 로그인·2차 인증·CAPTCHA는 직접 처리해야 합니다.

이 프로그램은 쿠팡 상품 URL 여러 개를 작업 목록으로 관리하고, 상품마다
**무료배송/착불배송**과 **임시저장/상품등록** 방식을 선택한 뒤 WING 등록 화면에
한 건씩 전달합니다. 이미지 편집이 필요한 상품은 임시저장으로 남기고, 바로 판매할
상품만 실제 상품등록 대상으로 구분할 수 있습니다. 작업 상태와 실패 사유는 앱을 닫아도
보존됩니다. 로그인·2차 인증·CAPTCHA만 Chrome에서 직접 처리하고, 자동입력이 끝나면
각 상품 행에서 고른 임시저장/상품등록 방식으로 저장한 뒤 다음 대기 상품을 처리합니다.

## 처음 한 번

1. [설치.bat](설치.bat)을 더블클릭합니다.
2. 설치가 끝나면 아무 키나 눌러 창을 닫습니다.

기존 `.venv`가 삭제된 Python을 가리키는 경우에도 `설치.bat`이 이를 감지해 다시 만듭니다.
Python 자체를 찾지 못하면 Python 3.12를 설치한 뒤 `설치.bat`을 다시 실행하세요.

## 실행

1. 검은 실행창 없이 열려면 [쿠팡상품등록_실행.vbs](쿠팡상품등록_실행.vbs)을 더블클릭합니다.
   기존 [실행.bat](실행.bat)을 사용해도 숨김 실행기로 전달된 뒤 검은 창이 바로 닫힙니다.
   프로그램이 이미 실행 중이면 두 번째 창은 열리지 않고 기존 창을 사용하라는 안내가
   표시됩니다. 작업 목록 충돌을 막기 위한 정상 동작입니다.
   프로그램이 열리면 자동입력 전용 Chrome의 WING 상품등록 화면을 준비합니다. 처음
   한 번 이 창에서 WING에 로그인하면 전용 프로필에 로그인 상태가 유지됩니다. 비밀번호나
   쿠키를 프로그램이 읽거나 저장하지 않습니다. 이전 실행에서
   `WING 화면 열림·입력 대기`로 남은 상품은 `등록 대기`로 자동 복구되므로, 실제 작업이
   진행 중이지 않은데 진행 중으로 표시되지 않습니다.
   **Chrome/WING 다시 준비**를 누르면 이미 실행 중인 전용 Chrome도 WING 탭을 찾아
   화면 앞으로 가져오며, WING 탭이 없으면 새로 엽니다.
2. 상단 **여러 상품 일괄등록 대기열**에 쿠팡 상품 URL을 한 줄에 하나씩 붙여넣고
   **URL 목록에 추가**를 누릅니다.
   상단·하단 고정페이지를 바꾸려면 바로 위 **고정페이지 이미지 삽입** 영역에서
   각각 `이미지 삽입/변경`을 누릅니다. 선택한 이미지는 다음 실행에도 유지됩니다.
3. 표 맨 앞의 **등록 선택** 체크박스에서 이번에 자동등록할 상품만 체크합니다.
   체크를 해제한 상품은 삭제되지 않고 목록과 설정이 그대로 보관됩니다. 위의
   **전체 상품 선택/해제** 체크박스로 한 번에 선택하거나 해제할 수도 있습니다.
4. 각 상품 행의 독립된 두 버튼에서 **무료배송** 또는 **착불배송**을 선택합니다.
   한 상품의 선택을 변경해도 다른 상품에는 영향을 주지 않습니다. 동일한 방식이면
   `대기 상품 전체 무료배송/착불배송` 버튼을 사용할 수 있습니다.
5. 같은 행에서 이미지 편집이 필요한 상품은 **임시저장**, 바로 등록할 상품은
   **상품등록**을 선택합니다. 두 선택이 모두 있어야 등록 대기 상태가 됩니다.
   상세페이지 문구를 확인하고 자연스럽게 만들 상품은 기본값인 **한국어 자연화**를
   유지합니다. 중국어는 자연스러운 한국어로 번역하고, 어색한 한국어는 맞춤법·띄어쓰기와
   표현을 교정합니다. 이미 자연스러운 한국어와 글자 없는 이미지는 그대로 유지됩니다.
   어떤 문구도 바꾸지 않을 상품만 **원본 유지**를 선택합니다.
6. **다음 상품 자동입력 시작**을 누릅니다. 프로그램이 체크된 상품만 순서대로 처리합니다.
   카탈로그를 검색하고 아이템위너
   가격이 있는 옵션을 선택한 뒤 판매가, 재고 999개, 배송비, 출고 9일, 반품배송비,
   상품정보고시, KC 구매대행, 상세페이지 이미지를 실제 WING 폼에 입력합니다.
7. 입력이 끝나면 행에서 선택한 **임시 저장** 또는 **상품등록** 버튼을 실제로 실행합니다.
   상품등록이 완료되면 WING의 **새로운 상품등록**을 자동으로 누릅니다.
8. 실패 상품은 사유를 남기고 다음 대기 상품으로 자동 이동합니다. 저장/등록 완료 후에도
   다음 등록 대기 상품이 있으면 연속으로 자동입력을 시작합니다.

상세 이미지가 WING의 한 번 업로드 한도인 10장을 넘으면 원본 순서를 유지한 채
세로형 업로드 패널 10장 이하로 자동 결합합니다. 각 패널은 WING 권장 높이 안에서
분할되며 원본 파일은 변경하지 않습니다. 재시도 중 원상품 사이트에서 이미지를 다시
받지 못하면 이전 시도에서 저장한 정상 상세 이미지를 재사용합니다.

완료된 상품을 다시 시험하거나 재등록하려면 표에서 해당 행을 선택하고
**선택 상품 다시 등록**을 누릅니다. 배송비·등록 방식·이미지 설정은 유지되고, 완료 표시와
이전 매칭가·반품배송비·원산지·등록상품 ID만 초기화되어 `등록 대기`로 돌아갑니다.

목록에서 필요 없는 상품은 맨 앞 체크박스를 선택한 뒤 **체크 상품 삭제**를 누릅니다.
확인창에 삭제할 상품 개수가 표시되며, 확인하면 체크한 상품들을 작업 목록과 저장 목록에서
한꺼번에 삭제합니다. 해당 상품의 번역·옵션 이미지 작업 폴더도 함께 삭제됩니다.

### 상세페이지 한국어 교정·번역 이미지

1. 일괄등록 표에서 상품을 선택합니다.
2. **선택 상품 상세 이미지 넣기**로 상세 이미지들을 순서대로 선택합니다.
3. 프로그램이 원본을 보존하고 `data/translation_jobs/{작업ID}`에 원본, 한국어 이미지
   지시서, 결과 폴더를 만듭니다. Codex 요청도 클립보드에 복사됩니다.
4. 현재 Codex 대화에 요청을 붙여넣어 한국어 이미지를 생성합니다. 각 이미지의 문구를
   먼저 확인해 중국어는 자연스러운 한국어로 번역하고, 어색한 한국어는 뜻을 유지해
   교정합니다. 제품 사진과 레이아웃, 숫자·치수·단위·모델명은 유지합니다.
5. 필요한 경우 **내 워터마크 넣기**에서 PNG/JPG 로고 또는 문구를 선택하고 위치,
   대각선 방향, 투명도와 크기를 지정합니다. **선택 상품 옵션 이미지 넣기**로 옵션
   이미지를 추가하면 옵션 이미지와 상세이미지에 같은 워터마크를 적용합니다. 쿠팡 메인
   대표이미지는 변경하지 않으며 설정은 다음 실행에도 유지됩니다.
6. **한국어 결과 불러오기**로 생성 결과를 넣습니다. 워터마크 사용이 켜져 있으면
   원본과 번역본을 보존한 채 별도 복사본에 자동 적용됩니다. 설정을 바꾼 뒤
   **선택 상품 결과에 워터마크 적용**으로 다시 만들 수도 있습니다.
7. 한국어 문구, 숫자, 치수, 단위, 모델명, 워터마크와 이미지 순서가 모두 맞으면
   **한국어 결과 검수 승인**을 누릅니다.

프로그램의 **오늘 작업 예정 상품**과 **상품당 평균 이미지**를 조절하면 기본 작업량과
오역 수정 등을 위한 20% 재작업 여유를 포함한 예상 이미지 수를 확인할 수 있습니다.
상품 10개 × 5장은 기본 50장·재작업 포함 약 60장이고, 상품 20개 × 5장은 기본
100장·재작업 포함 약 120장입니다. 이 값은 하루 작업 계획을 위한 계산이며 Plus의
보장된 일일 한도를 뜻하지 않습니다.

상세 원본이 준비됐거나 한국어 결과가 미검수 상태인 상품은 실제 **상품등록** 대기열로
넘어가지 않습니다. 편집을 더 해야 한다면 **임시저장**으로 진행할 수 있습니다.
검수 승인된 한국어 결과는 원본 대신 상품 상세 이미지로 등록 계획에 반영됩니다.

작업 목록은 `data/batches/current_batch.json`에 자동 저장됩니다. 중복 URL은 다시
추가되지 않으며 한 번에 한 상품만 `WING 자동입력 진행 중` 또는
`최종 실행 확인 대기` 상태가 됩니다.

상품 등록 준비값은 다음 기본값을 사용합니다.

- 판매가: WING 카탈로그 매칭가와 동일
- 재고수량: `999`
- 출고 소요일: `9일`
- 사용자 선택 항목: 상품마다 큰 버튼으로 **무료배송/착불배송** 중 하나만 선택
- 반품배송비(편도): 쿠팡의 전체 입력 범위 `0원~25만원`과 알려진 상한 금액 단계를
  프로그램 데이터에 보관합니다. 최저 판매가가 10만원 미만이면 판매가보다 낮은
  가장 큰 만원 단위를 먼저 사용합니다(예: 37,260원 → 30,000원). 상품·배송조건에
  따라 WING이 더 낮은 범위(예: `0원~20,000원`)를 표시하면 그 상한을 읽어 입력칸을
  자동으로 고친 뒤 최대 3회 다시 제출하며, 실제 입력값까지 확인합니다.
- 상품정보제공고시: `기타 재화 / 상세페이지 참조`
- KC 인증: `구매대행 상품`
- 원산지: 링크와 상세정보에서 실제 제조국을 확인해 상품마다 입력
- 상세페이지 입력 방식: WING의 `에디터 작성`
- 상세페이지 정제: 다른 판매자의 상호·연락처·QR·자체 배송/교환 안내는 제거 후보로 분류
- 고정페이지: 저장된 리빙레드 상단·하단 이미지를 자동 삽입

### 상세페이지 정제 원칙

고정페이지 순서는 **리빙레드 상단 → 정제된 상품 설명 → 리빙레드 하단**으로 고정됩니다.
기본 파일은 `assets/fixed_pages/livingred_top.png`와
`assets/fixed_pages/livingred_bottom.png`이며, 앱에서 각각 다른 이미지로 바꿀 수 있습니다.
일괄등록 화면에서 상단·하단 이미지를 미리 확인하고 언제든지 교체할 수 있으며,
여러 이미지를 선택하면 선택 순서대로 삽입됩니다. 변경값은
`data/settings/fixed_pages.json`에 저장됩니다. `리빙레드 기본 상·하단 이미지로
되돌리기` 버튼으로 기본 파일을 다시 적용할 수 있습니다.
다른 판매자의 고정영역은 판매자 상호, 전화번호·고객센터, 카카오톡·위챗·QQ,
QR 코드, 자체 배송·교환·반품 안내를 기준으로 감지합니다. 상품 특징, 규격·치수,
옵션·구성, 사용법·주의사항은 유지합니다. 확신이 낮은 영역은 자동 삭제하지 않고
WING 에디터 입력 전 미리보기 확인 대상으로 남깁니다.

현재 앱은 이 규칙과 고정페이지 파일 순서를 저장하고, 자동입력 과정에서 WING 이미지
업로드를 거쳐 에디터 상세설명에 반영합니다. 최종 **상품등록/임시 저장** 실행은 각
상품 행에서 사용자가 고른 처리 방식에 따라 진행됩니다.

결과는 `data/reports` 폴더에 JSON 파일로 저장됩니다. 비밀번호, 쿠키, 인증토큰은 입력하지
마세요. 입력하더라도 흔한 형태는 자동으로 삭제하지만, 애초에 적지 않는 것이 가장
안전합니다.

## 현재 범위

- 구현: 여러 URL 입력, 중복 제거, 상품별 무료/착불과 임시저장/상품등록 선택,
  작업 자동 저장/복원, 카탈로그와 아이템위너 옵션 자동 선택, 판매가·재고·배송·출고일·
  반품배송비·KC·상품정보고시 자동입력, 고정 상하단 및 상세 이미지 WING 에디터 적용,

## WING 실제 화면 확인 결과

- 상품 등록 주소: `https://wing.coupang.com/tenants/seller-web/vendor-inventory/formV2`
- 신규 등록용 검색은 **상품 등록 > 카탈로그 매칭하기**에서 수행합니다.
- 별도 **카탈로그 매칭관리** 메뉴는 이미 등록·승인된 내 상품의 사후 매칭 요청 화면입니다.
- 상품 `productId=9164263934` 검색에 성공했고, 결과에 최근 28일 조회수, 상품별점 표시,
  배송정보와 판매 옵션 목록이 노출되는 것을 확인했습니다.
- 사용자가 4개 판매옵션을 선택해 등록폼까지 이동했고, 상품등록 버튼이 활성화되는 것을
  확인했습니다. 상품등록·임시저장·중간저장은 수행하지 않았습니다.
- 등록폼에서 **취소**해 다른 WING 화면으로 빠져나왔으며 미저장 등록 내용이 남지 않은
  것을 확인했습니다. Phase 0 기술검증은 안전하게 종료됐습니다.
